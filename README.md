# Checking for understanding · Chunking and sequencing

A 40-minute whole-staff professional learning session on two NSW explicit teaching strategies, built to run on a 16:9 projector straight from the browser.

**Open the presentation:** https://ccutter379.github.io/explicit-teaching-cfu-chunking/

## Running it

| Key | What it does |
|---|---|
| → · Space · click · clicker forward | Next. On a check for understanding, reveals the answer first, then moves on |
| ← · clicker back | Back one step |
| A | Show every answer on the slide (again to hide) |
| T | Start or stop the slide's timer (other lengths in the control bar) |
| P | Presenter view: speaker notes, session clock, timer and next slide in a separate window |
| O | All slides |
| F | Full screen |
| B | Black screen |

The page is one self-contained file (fonts and images built in), so it also runs offline from a USB stick.
